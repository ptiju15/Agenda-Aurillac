# Agenda Aurillac — version iPhone

Cette version est une petite application Web autonome basée sur la grille de référence Excel.

Fonctions :
1. Agent + date -> code et type
2. Date -> les 30 agents et leur activité
3. Code K -> toutes les dates et tous les agents concernés

## Utilisation iPhone
Pour l'utiliser comme une application installable :
1. Héberger ce dossier sur un hébergement HTTPS (GitHub Pages, Cloudflare Pages, etc.).
2. Ouvrir l'adresse dans Safari sur l'iPhone.
3. Bouton Partager -> « Sur l'écran d'accueil ».
4. L'icône ouvre l'application en plein écran.

Le fichier `data.json` contient les données issues de `agenda_Aurillac(3).xlsx`.
